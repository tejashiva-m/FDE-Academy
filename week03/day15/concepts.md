# FastAPI

## What is FastAPI?
FastAPI is a Python framework for building APIs quickly and cleanly. It makes it easy to create routes and return data in JSON format.

## Why use FastAPI?
FastAPI is popular because it is fast, simple to learn, and supports automatic documentation. It is a good choice for building modern web APIs.

## What is an API?
An API is an interface that lets different software systems communicate with each other.

## What is an endpoint?
An endpoint is a specific URL that a client can call to perform an action or receive data.

## What is a JSON response?
A JSON response is data returned in JavaScript Object Notation format, which is easy for applications to read and send.

## What is Uvicorn?
Uvicorn is a web server that runs ASGI applications such as FastAPI apps.

## What does --reload do?
The --reload option makes the server restart automatically whenever the code changes, which is helpful during development.

## Difference between Path Parameters and Query Parameters
Path parameters are part of the URL path, such as /employees/1. Query parameters are added to the URL after a question mark, such as /search?department=Cloud.

## What is Swagger UI?
Swagger UI is a built-in browser-based interface that shows all API endpoints and lets you test them.

## Why is API documentation important?
API documentation is important because it helps developers understand how to use the API, test it, and integrate with it correctly.
