# SQLite

## What is a database?
A database is a structured place to store data so it can be saved, searched, updated, and deleted in an organized way.

## What is SQLite?
SQLite is a lightweight database engine that stores data in a single file on disk. It is simple to use and does not require a separate server.

## What is a table?
A table is a collection of related data organized into rows and columns, similar to a spreadsheet.

## What is a row?
A row is one record in a table. For example, one employee's information is one row.

## What is a column?
A column is one field or attribute in a table, such as name, department, or salary.

## What is a primary key?
A primary key is a special column that uniquely identifies each row in a table. In this project, the id column is the primary key.

## What does AUTOINCREMENT do?
AUTOINCREMENT automatically gives each new row a unique increasing numeric id value.

## Difference between fetchone() and fetchall()
fetchone() returns one row at a time, while fetchall() returns all matching rows at once.

## Why use parameterized queries with ?
Parameterized queries help prevent SQL injection and make it easier to safely pass values into a query.

## What is SQL injection?
SQL injection is a security attack where an attacker inserts harmful SQL code into a query to manipulate the database.

## Difference between INSERT, SELECT, UPDATE, and DELETE
- INSERT adds new data to a table.
- SELECT reads data from a table.
- UPDATE changes existing data.
- DELETE removes data from a table.

## What is CRUD?
CRUD stands for Create, Read, Update, and Delete. These are the four basic operations for managing data in a database.
